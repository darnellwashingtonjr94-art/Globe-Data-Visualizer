# Globe-Data-Visualizer
Enterprise-Globe-Visualizer is a real-time, 3D network topology monitoring tool. Using Three.js and WebGL, it renders a transparent globe overlaying live traffic data. The backend ingests NetFlow, sFlow, and SNMP metrics, resolves IPs to geolocation coordinates via MaxMind, and streams bandwidth heatmaps and HUD alerts via WebSockets to the UI.
